Sistema de Bolsa Laboral
¿Qué es este proyecto?
Es una aplicación de escritorio desarrollada en Java diseñada para conectar a personas que buscan empleo con empresas que ofrecen vacantes. El sistema administra todo el proceso: desde el registro de usuarios hasta la selección del candidato ideal mediante un algoritmo inteligente.
Características Principales
Búsqueda Inteligente (Matcheo):** El sistema evalúa automáticamente a los candidatos y recomienda los mejores perfiles para cada oferta de trabajo.
Sistema de Roles: Vistas y permisos diferentes dependiendo de si eres un Candidato, una Empresa o el Administrador del sistema.
Gráficas en Tiempo Real: El administrador puede ver estadísticas visuales sobre el estado del mercado laboral (empleados vs desempleados).
Respaldo en la Nube: Los datos se guardan automáticamente de forma local, con la opción de enviar una copia de seguridad a un servidor central.
